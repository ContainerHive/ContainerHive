# Contributing

ContainerHive welcomes contributions — bug reports, discussions, fixes, and new features. The
[contribution guidelines](https://github.com/ContainerHive/ContainerHive/blob/main/CONTRIBUTING.md) in the repository
describe the pull request flow, required quality standards, and the AI-generated contributions policy.

## Maintainers wanted

ContainerHive currently has a single maintainer: Timo Reymann. To keep reviews, releases, and urgent fixes going even
when that one person is unavailable, additional maintainers are welcome.

You do not take over the project: responsibilities and expectations are discussed before anything is assigned to you.
Shared ownership is the goal, not a handover.

If you are interested, reach out to [oss@timo-reymann.de](mailto:oss@timo-reymann.de) to talk details.

## What maintainers work on

- Reviewing and merging pull requests
- Cutting releases
- Triage of issues and pull requests
- Urgent fixes, including when the release process runs without the original maintainer
